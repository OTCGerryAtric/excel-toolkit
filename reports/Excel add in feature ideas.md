# Borrow the best ideas from Excel add-ins

The established Excel add-ins share a small core of features. A new add-in has to match these core features and can then stand out on the advanced ones. Every audit tool offers precedent and dependent tracing, a colour "formula map" of unique and inconsistent formulas, workbook compare, and error or hard-code checks. Every productivity suite offers text cleanup, fill-blanks, formulas-to-values, merge and split, and sheet management. The differences sit in deeper features. Examples include Operis OAK's formula Reconstruct with pruning of untaken IF branches, Spreadsheet Detective's AutoNames (formulas rewritten with row and column labels), PerfectXL's FAST/ICAEW standards checks, compare tools that align inserted rows before diffing, and Macabacus's keyboard-driven format cycles and AutoColor. A Python add-in is well placed for analysis-heavy features that are awkward in VBA: formula parsing, dependency graphs, fuzzy dedupe, regex, SQL over sheets, workbook diff and HTML or PDF reports. The bigger design decision is the framework, not the feature list. PyXLL runs in-process via COM and suits instant hotkey tools on Windows, but its edits wipe Excel's undo stack. Office.js-based routes (xlwings Server/Wasm) gained native undo in September 2025, but limit shortcut keys and add a round trip to every action. Python in Excel (`=PY`) cannot automate the workbook at all. The report ends with a starter set of about ten features: cheap to build, used daily, and good foundations for the harder features later.

## Tracing and formula maps are table stakes; reconstruction and explanation are the frontier

The auditing market agrees on a core of four features. These are multi-cell precedent and dependent tracing, a temporary colour overlay for unique, copied and inconsistent formulas, structural workbook compare, and automated risk checks. **Arixcel Explorer** pops up a formula's structure with jump-to-precedent on Ctrl+Q. It traces several cells at once, overlays a "formula map" showing inconsistencies, hard-codes and external references, and auto-aligns inserted rows and columns before comparing ([SoftwareOne](https://platform.softwareone.com/product/arixcel-explorer/PCP-1927-2429)). **Macabacus** adds Trace In/Out, step-by-step breakdown of nested formulas, and a live-updating Formula Flow ([Macabacus](https://macabacus.com/excel/formula-auditing)). It also has a Model Check of **"50+ checks"**, though the individual rules are not published ([Macabacus Model Check](https://macabacus.com/excel/model-check)). **PerfectXL Risk Finder** analyses a file in about **10 seconds**. It reports circular-reference loop paths, very-hidden content, hard-coded numbers in formulas (ignoring constants like 100 and 1000), unlocked cells and **FAST/ICAEW** conformance, then exports a one-click PDF report ([PerfectXL Risk Finder](https://www.perfectxl.com/products/perfectxl-risk-finder/)).

The tools differ on features that explain a formula rather than just locate it. **OAK's Reconstruct** rebuilds a formula's precedent chain down to the inputs. The Professional edition prunes calculations not on the active path, such as the untaken branch of an IF ([Operis OAK](https://www.operisanalysiskit.com/); [OAK5 launch](https://www.operis.com/operis-launch-oak5-the-latest-version-of-the-worlds-favourite-financial-modelling-software/)). **Spreadsheet Detective's AutoNames** rewrites `=C12*D7` into label language taken from row and column headers, with hyperlinks to each precedent. It also offers per-formula sensitivity analysis and a reviewer workflow that marks formulas as verified, questionable or erroneous ([Spreadsheet Detective](https://spreadsheetdetective.com/main/)). **FormulaDesk Math** renders formulas in symbolic maths notation ([FormulaDesk](https://www.formuladesk.com/)). **Ablebits** edits long formulas in a tree view ([Ablebits](https://www.ablebits.com/excel-suite/index.php)). Microsoft's own **Inquire** add-in covers the basics: a workbook analysis report, relationship diagrams, Clean Excess Cell Formatting and Spreadsheet Compare. It is available only in Windows enterprise-tier Microsoft 365, and admins can disable it ([Microsoft Support](https://support.microsoft.com/en-US/Excel/analyze-a-workbook-with-spreadsheet-inquire)).

In the feasibility columns below, E means easy, M moderate and H hard. These ratings are the research team's architectural judgement, not measured results. "Offline" means Python reading the .xlsx file directly (openpyxl plus a formula tokenizer or graph library) rather than talking to live Excel.

| Feature idea | Offered by | PyXLL (COM) | Office.js + Python | Notes for a Python build |
|---|---|---|---|---|
| Multi-cell precedent/dependent trace and jump | Arixcel, Macabacus, OAK, Prof. Excel, Inquire | M | E–M | COM `DirectPrecedents` is same-sheet only, so cross-sheet tracing needs your own parser. Office.js `getDirectPrecedents` spans sheets ([MS Learn](https://learn.microsoft.com/en-us/javascript/api/excel/excel.range)) |

The **formula map**, **risk checks** and **audit report** rows are where the market's core features overlap with what Python does well. AutoNames, FAST checks and structure-aware compare are the differentiators that only one or two vendors currently own.

## Banker shortcuts turn formula text into a keystroke

Macabacus is the reference for keyboard-driven productivity, and its features break into three groups that are all plain operations on the selection. The first group is format cycles. One hotkey steps through preset fills, number formats, alignments or indents, and wraps back to the first after the last ([Macabacus formatting](https://macabacus.com/excel/formatting)). Cycle colours come from a user palette imported from formatted cells ([Macabacus Color Palettes](https://help.macabacus.com/article/766-color-palettes)). The second group is **AutoColor**. It classifies every cell as a numeric input, a partial input (for example `=A1+12.34`), a same-sheet formula, a cross-sheet formula, a cross-workbook link or a data-provider pull, and applies the finance colour convention to each ([Macabacus Colors](https://macabacus.com/docs/excel/colors)). The third group is formula rewriting. **Flip Sign** multiplies formulas by -1. **Anchor** cycles `$` styles across a whole selection, which F4 cannot do. **Error Wrap** toggles IFERROR on and off. **Fast Fill Right/Down** works out the fill extent from neighbouring data and skips spacer columns, and **Paste Exact** copies formulas without shifting their references ([Macabacus Formulas & Data](https://www.macabacus.com/docs/excel/formulas-data)). Professor Excel covers similar ground without the hotkey focus. It offers IFERROR/IFNA and **ROUND/ROUNDUP/ROUNDDOWN wraps**, "append an operation to every formula", Paste Exact Formula, Clean Formulas (turning `=+` into `=`), Center Across Selection, and display in thousands or millions ([PE features](https://professor-excel.com/professor-excel-tools-features/)).

Users value these features and also report problems with them. Reviewers praise Macabacus's formatting tools and shortcuts ([Capterra](https://capterra.com/p/10011368/Macabacus/reviews/)). Others report that undo is unreliable after shortcuts ([G2](https://g2.com/products/macabacus-macabacus/reviews)) and that it freezes while tracing precedents ([Software Advice](https://www.softwareadvice.com/cms/macabacus-profile/reviews/)). Macabacus maintains its own undo system because code that changes a sheet clears Excel's undo stack ([Macabacus Undo/Redo](https://www.macabacus.com/docs/excel/undo-redo)). The general suites barely offer format cycling, which leaves an open niche ([Excel Campus](https://www.excelcampus.com/vba/font-fill-color-style-excel-add-in/)).

|---|---|---|---|---|
| Number/fill/font format cycle on a hotkey | Macabacus (Excel Campus offers static styles only) | E | M | Keep the cycle position per cell in Python, or infer it from the current format |
| Alignment/indent cycle, Center Across Selection | Macabacus, Prof. Excel | E | M | |
| AutoColor (inputs, formulas, cross-sheet, external, partial inputs) | Macabacus, FactSet, Ampler | E | M | Bulk-read `.Formula`, classify with regex or tokenizer, write colours. Chunk large sheets in Office.js |
| Flip sign / IFERROR / ROUND / parentheses wrap and unwrap | Macabacus, Prof. Excel, ASAP (flip sign) | E | E–M | Pure string rewriting. ROUND wrap is documented only by Prof. Excel |
| Anchor ($) cycle across selection | Macabacus, Prof. Excel | M | M | The tokenizer is the hard part. openpyxl ships one |
| Fast Fill Right/Down with spacer skipping | Macabacus | E–M | M | |

## Cleanup, navigation and hygiene tools are what users actually run every day

The only real usage data in the research is **ASAP Utilities' telemetry of its 25 most-used tools in 2024**. Mundane cleanup dominates it. The top two are trimming spaces, followed by UPPERcase, converting numbers stored as text, deleting empty rows, adding text before or after each cell, and the other case changes. Further down are converting text to dates (#13), formulas to values (#14), fill blanks down (#18), colour duplicates (#19), export sheets as separate files (#20) and **flip sign** (#21). The meta-tools **"Find and run a utility"** (#17) and **"Start the last used utility again"** (#25) also make the list ([ASAP news](https://asap-utilities.com/news-detail.php?m=375)). The two meta-tools address a problem a reviewer described, that finding the right tool in a big suite takes time ([Capterra ASAP](https://www.capterra.ca/reviews/172223/asap-utilities-for-excel)). Kutools markets **300+ features** in nine groups, now including an AI group that writes and explains formulas ([Kutools](https://www.extendoffice.com/product/kutools-for-excel.html)). Ablebits lists **70+ tools** with **fuzzy duplicates, regex tools and a Formula Editor tree** ([Ablebits](https://www.ablebits.com/excel-suite/index.php)). XLTools offers workbook **version control with rollback** and **SQL joins over sheets** ([XLTools](https://xltools.net/)).

Modelling-hygiene tools are a separate cluster, and most of them fit Python well because they inspect and rewrite workbook structure. Professor Excel offers Reduce File, Layout Manager (gridlines, zoom and grouping across all sheets), Font Manager, unhide very-hidden sheets, a Name Manager that includes hidden names, Workbook Info counts, a status-bar file-info display, and an Export Manager that loops over a list of values to produce PDFs ([PE features](https://professor-excel.com/professor-excel-tools-features/)). ASAP adds "fix incorrect last cell", fix trailing minus signs, natural sort and JSON export ([ASAP popular](https://www.asap-utilities.com/popular.php)). Kutools' **Grid Focus** highlights the active row and column, and its **Navigation Pane** lists sheets and names ([Kutools](https://www.extendoffice.com/product/kutools-for-excel.html)). Spreadsheet Detective has a sheet and name navigator that searches as you type ([Spreadsheet Detective](https://spreadsheetdetective.com/main/)).

## The framework decides which features feel instant

**PyXLL** fits a Macabacus-style tool most naturally. It binds shortcuts directly with `@xl_macro(shortcut="Ctrl+Shift+R")` and provides ribbon XML, context menus, Application events, Qt task panes and the full COM object model ([PyXLL shortcuts](https://www.pyxll.com/docs/userguide/macros/shortcuts.html); [PyXLL index](https://www.pyxll.com/llms.txt)). Its costs are that it runs only on Windows and that COM edits clear the undo stack, so you would need your own undo log as Macabacus has. **Office.js** routes, including xlwings Server and xlwings Wasm, cover Mac and the web, and expose cross-sheet `getPrecedents`/`getDependents` ([MS Learn](https://learn.microsoft.com/en-us/javascript/api/excel/excel.range)). Since **September 2025** their changes can be undone natively, with each `context.sync()` counting as one undo step ([Microsoft 365 Dev Blog](https://devblogs.microsoft.com/microsoft365dev/excel-announces-undo-support-for-3rd-party-add-ins/)). Their shortcuts have limits: each needs a modifier plus exactly one of A–Z, 0–9, `-`, `_` or `+`. Browser-reserved combinations such as Ctrl+Shift+N cannot be overridden on the web, and shortcuts do not fire while the task pane has focus ([MS Learn shortcuts](https://learn.microsoft.com/en-us/office/dev/add-ins/design/keyboard-shortcuts)). xlwings Wasm adds Pyodide limits: no threading, a 2 GB memory cap, and ribbon buttons that don't handle errors ([xlwings Wasm limitations](https://server.xlwings.org/en/latest/wasm_limitations/)). **Python in Excel** runs in an isolated cloud container and cannot read or change formulas or formatting, so it is irrelevant for this kind of add-in ([Microsoft Q&A](https://learn.microsoft.com/en-us/answers/questions/4457428/limits-of-python-implementation-in-excel-365)).

This suggests a hybrid design. Run hotkey actions in-process through PyXLL, or through Office.js if Mac or web support matters. Run heavy analysis such as compare, risk scans, the dependency graph and reports offline against the saved .xlsx with openpyxl and a formula tokenizer, and show the results in a task pane or HTML report. Operis made the same split when it moved Summarize, Map and Compare into a 64-bit process outside Excel ([OAK5 launch](https://www.operis.com/operis-launch-oak5-the-latest-version-of-the-worlds-favourite-financial-modelling-software/)). The research found no measured latency comparison between the frameworks, so the claim that PyXLL feels faster for hotkeys rests on architecture alone.

## Suggested starter set: ten features, two weeks each at most

These ten are chosen for high daily use, low build cost (rated E in the tables above) and value as foundations for the harder features. The order assumes PyXLL on Windows.

| 2 | Text cleanup pack: trim, case cycle, text-to-number, text-to-date | Top six ASAP tools; pure value transforms | ASAP #1–5, #7–13 | — |
| 3 | Formulas to values, fill blanks down, delete blank rows | Trivial to build, used constantly | ASAP #5, #14, #18 | — |
| 4 | Formula wrappers: IFERROR, ROUND and parentheses toggle, plus flip sign | String rewriting on a selection; banker favourite | Macabacus, Prof. Excel, ASAP #21 | Anchor cycle (adds the tokenizer) |
| 5 | Number-format and fill-colour cycles on hotkeys | Open gap in general suites; only finance tools do it | Macabacus reviews ([Capterra](https://capterra.com/p/10011368/Macabacus/reviews/)) | Alignment/indent cycles, palette editor |
| 6 | AutoColor (input / formula / cross-sheet / external / partial input) | One formula classifier serves formatting and auditing alike | Macabacus, FactSet | Formula map, risk checks |
| 7 | Workbook hygiene scan: hidden/very-hidden sheets, hidden/unused/broken names, external links, error cells | Read-only, so no undo worries. Mostly openpyxl lookups | PerfectXL, Prof. Excel, Inquire | Full risk-check engine, FAST rules |
| 8 | Unique-formula map overlay + list in task pane | Core of every audit tool; R1C1 grouping is simple | Arixcel, PerfectXL, OAK, Spreadsheet Detective | Inconsistency flags, compare |
| 9 | Sheet navigator / table of contents | Quick win in a task pane; good shell for later panes | Kutools, Ablebits, Prof. Excel | — |
| 10 | HTML audit report from items 7 and 8 | Shows off Python's strength; output can be shared | PerfectXL, OAK, Inquire | PDF report, reviewer sign-off |

Build a small **undo log** alongside items 2–6. On PyXLL this means snapshotting the selection's formulas and formats before each change. Without it, every editing feature risks the "unreliable undo" complaint that follows Macabacus.

## Conclusion

The research suggests competing on a narrower set of features rather than more of them. Kutools-scale breadth (300+ features) is not worth matching. ASAP's telemetry shows that fewer than 25 cleanup actions account for most real use, and the audit vendors all share the same four core features. A Python add-in is distinctive where it builds on parsing and graphs, which are hard in VBA and easy in Python. One formula tokenizer and dependency graph can serve AutoColor, the anchor cycle, formula maps, AutoNames-style explanations, FAST rule checks and structure-aware compare. In effect it delivers features that today require buying both Macabacus and PerfectXL.

Several unknowns should shape the next steps. Arixcel's official documentation, Macabacus's 50 Model Check rules and Macabacus's default shortcut list were not retrievable. There are no independent benchmarks of compare accuracy or hotkey latency. Reddit sentiment could not be gathered. The cheapest way to fill these gaps is to trial Arixcel and Macabacus directly and to prototype the tokenizer-plus-graph core first, since most of the differentiating features depend on it.
